\# v1.1.1 — Reproducibility Distribution and Metadata Update



\*\*Release date:\*\* 2026-11-15



\## Overview



Version v1.1.1 provides an updated public distribution of the existing 282-run drug–target affinity model-comparison reproducibility materials.



This release reorganizes repository distribution and citation metadata. It does not represent additional experiments, new model training, or independent experimental replication.



\## Evidence Scope



The evidence package retains:



\- 126 original KIBA/Davis campaign runs.

\- 36 matched-optimizer AdamW capacity-control runs.

\- 30 additional KIBA second-split runs.

\- 30 GPCR extension runs.

\- 60 protease extension runs.



The historical 36-run Adam exploration remains auxiliary and excluded from the 282-run evidence total.



\## Reproducibility Materials



The established `revisions/v1.1.0/` directory structure is retained for compatibility.



The package contains 69 independently checksummed ZIP parts in `revisions/v1.1.0/payload\_parts/`, together with the existing payload index and reconstruction script.



The release preserves the documented scientific scope, limitations, statistical corrections, and reproducibility caveats of the underlying evidence package.



\## Repository Updates



\- Updated README and citation metadata for the v1.1.1 distribution.

\- Updated repository links to the current public distribution.

\- Retained the existing reproducibility payload and verification records.

\- Preserved the previously documented licensing distinctions.
